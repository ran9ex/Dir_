# درع (Dir') — بوابة حماية سعودية-عربية لاستخدام الذكاء الاصطناعي

## التشغيل
```
pip install -r requirements.txt
streamlit run app.py          # الواجهة
python -m pytest -q           # 153 اختباراً
python bench_ml.py            # (اختياري) قياس القواعد مقابل النماذج، بعد: pip install sentence-transformers transformers torch
```
بدون GPU وبدون إنترنت تشتغل القواعد كاملة. طبقة النماذج اختيارية: فعّليها من الشريط الجانبي، وإن فشل التحميل يكمل درع بالقواعد.

## تدريب مصنّف الهجمات العربي (اختياري، يرفع قوة الذكاء الاصطناعي)
1. افتحي https://colab.research.google.com ← File ← Upload notebook ← `train_classifier.ipynb`.
2. Runtime ← Change runtime type ← T4 GPU، ثم شغّلي الخلايا بالترتيب وارفعي `dir_shield_v2.zip` لما يطلب.
3. في آخر الدفتر ينزل `dir_attack_clf.zip`. فكّيه وضعي المجلد `dir_attack_clf` بجانب `app.py`.
4. `python bench_ml.py` يطبع جدول قواعد / نموذج / هجين، ويظهر في الواجهة تلقائياً عند تفعيل طبقة النماذج.
بيانات التدريب مولَّدة بالقوالب (`train_data.py`) وبعيدة عن جمل الاختبار اليدوية. لم يُجرَّب التدريب في بيئة التطوير، فأرسلي لي أي خطأ يظهر.

## الفكرة بجملة
الموظف يلصق بيانات عميل في أداة ذكاء اصطناعي؛ درع يحجب الهوية والآيبان والجوال (بفحص checksum)، يصد الحقن بالعربي، ويطلع تقرير PDPL.

## هندسة الطبقات
قواعد + checksum (دقيقة للهوية/الآيبان) ← كاشف أرقام مكتوبة بالحروف ← طبقة نماذج (تشابه دلالي، نية الحقن، أسماء NER) تضيف دليلاً ولا تحجب وحدها ← خزنة رموز لكل جلسة ← حارس مخرجات ← درجة خطورة ← سجل تدقيق بدون نصوص خام ← درجة ثقة للجلسة (تُعلَّق بعد 3 محاولات).
